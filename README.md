# Social Links Profile

A responsive **Social Links Profile** built using **HTML** and **CSS** as part of the Frontend Mentor challenge.

## 🚀 Features

* Responsive design
* Clean and modern UI
* Hover effects on social links
* Built with HTML5 and CSS3

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox

## 📂 Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
